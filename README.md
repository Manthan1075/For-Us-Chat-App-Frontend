personal chat app project

Technology Used:

Frontend:

1. React 
2. Tailwind 
3. Shadcn

Backend:

1. Node 
2. Express 
3. Mongo DB
4. Image Kit ( Store Image On Cloud)


Features:

1. Authentication (Login only)
2. Chat With All Users In System
3. Send Edit Delete Reply React High Light Messages
4. Mini Profile 
5. Send Image 
6. Create New User ( Admin Only )
